# Reference index

Исходный материал: 20 production-слайдов и 12 дополнительных листов графической библиотеки 1920×1081, полученных 11 сентября 2026 года. Для репозитория используются оптимизированные JPEG-превью; смысл, композиция и цветовой режим сохранены.

Подробная карта соответствий находится в `../layouts/slide-patterns.md`.

## Смысловые группы

- Кейс: 01, 03, 13.
- Спикер: 02, 14.
- Нейро-подсказки / UI: 04, 05, 17.
- Возможности рекламного кабинета: 06, 07, 11, 15, 16.
- Покупательские метрики: 08, 09, 10, 18, 19.
- CTA и динамика инвестиций: 12, 20.

## Использование

При разработке нового слайда открыть:

1. ближайший по типу контента референс;
2. его вариант в противоположной теме, если он существует;
3. `contact-sheet.jpg`, чтобы проверить общий ритм системы.

Не использовать contact sheet как единственный источник для проверки мелкой типографики: финальную сверку делать по отдельному изображению.
