# Avito ПоДелу — presentation memory

Репозиторий фиксирует визуальную систему нового проекта **«Авито ПоДелу»** по 20 production-референсам и 12 дополнительным листам графической библиотеки. Это источник истины для дальнейшей разработки слайдов в том же стиле.

## С чего начинать

1. Прочитать `AGENTS.md`.
2. Использовать `brand/visual-style.md` как основной бренд-гайд.
3. Выбирать иконки, chips, strokes, 3D-материалы и data-компоненты по `brand/graphic-library.md`.
4. Брать размеры и цвета из `tokens/design-tokens.json`.
5. Выбрать композицию по `layouts/slide-patterns.md`.
6. Проверить текст по `content/editorial-style.md`.
7. Сверить формулировки референсов по `content/reference-copy.md`.
8. Для генерации слайда использовать `prompts/slide-agent.md`.
9. Сверить результат с production-референсами в `references/` и компонентами в `references/guides/`.

## Что определяет стиль

- крупная нейтральная гротескная типографика;
- уверенное левое выравнивание и строгая 12-колоночная сетка;
- постоянная сервисная строка в верхней части слайда;
- три режима холста: белый, светло-серый и зелёный;
- карточки с крупным скруглением без контуров и заметных теней;
- один главный визуальный приём на слайд: мокап, портрет, 3D-объект, диаграмма или крупная метрика;
- один кислотно-зелёный жест: рукописное подчёркивание либо большой stroke, связывающий cutout;
- cyan для цифровых метрик и графиков, фирменный bright green для акцентов и CTA;
- 2D tile-icons для плотных функциональных наборов и 3D-иконки/примитивы для hero-акцентов;
- согласованные материалы: metallic/fabric rim и matte/faceted glass;
- светлые и тёмные версии одних и тех же композиционных сценариев.

## Важное отличие от других проектов Avito

Этот проект нельзя автоматически смешивать со стилями репозиториев `Avito` и `avitoblack`. Здесь основой служат именно 20 production-референсов и 12 component-guides «Авито ПоДелу»: co-branding Avito × ПоДелу, верхняя мета-строка, зелёная система фонов, крупные округлые карточки и контролируемая 2D/3D-графика.

## Структура

- `AGENTS.md` — короткая оперативная память проекта;
- `brand/visual-style.md` — полное описание визуальной ДНК;
- `brand/graphic-library.md` — правила 2D/3D-графики, chips, strokes и инфографики;
- `tokens/design-tokens.json` — палитра, сетка, размеры, типографика;
- `layouts/slide-patterns.md` — библиотека композиций и карта 20 референсов;
- `content/editorial-style.md` — правила заголовков, подписей и чисел;
- `content/reference-copy.md` — точная текстовая база 20 референсов;
- `prompts/slide-agent.md` — производственный промпт для новых слайдов;
- `references/*.jpg` — оптимизированные визуальные эталоны;
- `references/contact-sheet.jpg` — обзор всей системы;
- `references/guides/*.jpg` — 12 дополнительных листов графической библиотеки;
- `references/guides/contact-sheet.jpg` — обзор всех component-guides.
